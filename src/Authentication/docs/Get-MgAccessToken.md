# Get-MgAccessToken

## SYNOPSIS
Gets an access token for the current Connect-MgGraph session. The token is cached and is only refreshed when it has less than 5 minutes of remaining lifetime or when -ForceRefresh is specified.

## SYNTAX

```
Get-MgAccessToken [[-Scopes] <String[]>] [-ForceRefresh] [-AsObject] [-ProgressAction <ActionPreference>]
 [<CommonParameters>]
```

## DESCRIPTION
Get-MgAccessToken returns an access token for the identity that is currently signed in via Connect-MgGraph.

A token is cached in-process per set of requested scopes. Calling the cmdlet again with the same scopes returns the cached token unless:

- The cached token has less than 5 minutes remaining before it expires, or
- The `-ForceRefresh` (alias `-Force`) switch is specified.

By default the cmdlet returns the access token as a `SecureString`. Use `-AsObject` to get a `Microsoft.Graph.PowerShell.Authentication.Models.MgAccessTokenInfo` object that also includes the token's expiry information and the scopes it was issued for.

You must call Connect-MgGraph before using this cmdlet.

If Connect-MgGraph was called with `-AccessToken` to supply a user-provided bearer token, the session has a single, fixed token: `-Scopes` and `-ForceRefresh` are not applicable in this case and the cmdlet throws an error if either is specified.

## EXAMPLES

### Example 1: Get the current access token as a SecureString
```powershell
PS C:\> Get-MgAccessToken
```

Returns the cached access token (requesting a new one if needed) for the scopes of the current session, as a SecureString.

### Example 2: Get an access token for specific scopes
```powershell
PS C:\> Get-MgAccessToken -Scopes "User.Read"
```

Returns a cached or freshly requested access token for the `User.Read` scope.

### Example 3: Force a new token to be requested
```powershell
PS C:\> Get-MgAccessToken -ForceRefresh
```

Bypasses the cache and requests a new access token.

> [!NOTE]
> `-Scopes` and `-ForceRefresh` cannot be used when Connect-MgGraph was called with `-AccessToken`; doing so throws an error since the session's token is fixed and not refreshable.

### Example 4: Get the access token with lifetime information
```powershell
PS C:\> Get-MgAccessToken -AsObject
Token      : System.Security.SecureString
ExpiresOn  : 11/3/2025 10:15:00 PM +00:00
ExpiresIn  : 00:59:58.1234567
Scopes     : {User.Read}
```

Returns an `MgAccessTokenInfo` object containing the token and its remaining lifetime.
