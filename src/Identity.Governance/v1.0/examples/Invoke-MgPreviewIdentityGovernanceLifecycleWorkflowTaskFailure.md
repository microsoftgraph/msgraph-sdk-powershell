### Example 1: Workflow with task failures

```powershell

Import-Module Microsoft.Graph.Identity.Governance

Invoke-MgPreviewIdentityGovernanceLifecycleWorkflowTaskFailure -WorkflowId $workflowId

```
This example will workflow with task failures

### Example 2: Workflow with no task failures

```powershell

Import-Module Microsoft.Graph.Identity.Governance

Invoke-MgPreviewIdentityGovernanceLifecycleWorkflowTaskFailure -WorkflowId $workflowId

```
